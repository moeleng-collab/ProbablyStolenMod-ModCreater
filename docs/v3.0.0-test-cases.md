# ModuleCrafter 3.0.0 实现测试用例

> 状态：**实现中，实机待验收**  
> 对应设计：`docs/v3.0.0-update.md`  
> 范围：制造工作量、专用模组强化上限、19 种专用效果的 +10／+12 里程碑。  
> 规则测试、构建和官方扫描已完成；游戏适配与 UI 用例仍需实机验收。

## 1. 测试分层

| 层级 | 目的 | 执行方式 |
| --- | --- | --- |
| 纯规则测试 | 验证工作量、晚数、上限、效果映射和状态回落 | 无 Unity 依赖的断言，沿用现有 `RulesTests`／`EnhanceRulesTests` 风格 |
| 游戏适配测试 | 验证材料、机器进度、实际产出、特殊标签与存档 | 游戏内制造、强化、读档和禁用／启用 |
| UI 验收 | 验证工作量与预计晚数、解锁提示、效果预览 | 新游戏、制造机、强化器和王尔德界面 |
| 回归测试 | 确保现有 2.x 行为未被误改 | 保留现有测试，仅更新明确被 3.0.0 替代的预期 |

计划中的纯规则接口名称仅用于描述断言目标，不代表现有代码：

```text
ModuleCrafterRules.GetWorkload(kind)
ModuleCrafterRules.ComputeActualNights(workload, currentSpeed)
ModuleCrafterEnhanceRules.MaxLevelFor(itemId, precisionUnlocked)
ModuleCrafterEnhanceRules.CanRequestEnhancement(..., precisionUnlocked)
ModuleCrafterSpecialEffectRules.Evaluate(itemId, level)
```

## 4. 专用效果通用断言

对全部 19 种专用模组逐一执行：

1. 等级 0～9 均返回 +0 基础效果。
2. 等级 10 返回第一次提升结果。
3. 等级 11 返回与等级 10 完全相同的结果。
4. 等级 12 返回第二次提升结果。
5. 从 10 手动降到 7 时恢复基础效果；从 12 手动降到 9 时恢复基础效果。
6. 稳固夹归零后恢复基础效果，再次升到 10 时只获得一次第一次提升，不累计。
7. 未解锁工艺时，游戏适配层不能达到 10；纯数据求值不得被用来绕过上限。
8. 现有 9 种通用模组的随机词条不受该映射影响。

建议增加数据完整性断言：

- 19 个物品 ID 均且仅出现一次，无遗漏、无重复、无未知 ID。
- 效果值按当前等级重算，不在原效果上反复累加。
- 非法等级输入按 0～12 夹紧，或按统一约定抛出参数异常；不得静默返回随机结果。

## 6. 特殊适配与边界用例

### 6.1 水培与蒸发器

- A01：营养果以外的作物不享受营养果模组增量。
- A02：梦帽菇中和的转食物、去违禁和产量效果同时存在，强化不能互相覆盖。
- A03：填料草在任何等级均不产种子，不能只强化产量而恢复种子。
- A04：水培走私 +10 与 +12 的作用范围按表扩大，非目标物品仍保持原违禁状态。
- A05：蒸发器只回收溶剂的限制不被强化解除；回收量百分比按最终等级计算。

### 6.2 DNA

- A10：基因稳定 +10 使用固定随机序列验证 49 保留、50 不保留数据盘；+12 不掷骰且始终保留。
- A11：正、负面筛选的额外提取只作用于对应方向；原版同时安装正反筛选时的阻断规则保持不变。
- A12：精准提取强化、掉级、读档后保留 `DNA_PRECISION_TRAIT_STRING`，不会变成未扫描状态。
- A13：精准提取 +10／+12 的保留目标／数据盘效果与扫描特性过滤同时生效。

### 6.3 打印与警报

- A20：金属打印和 CNC 的解锁标签在强化、掉级和读档后保持，不因效果数值变化而丢失。
- A21：CNC 工作量修正只作用于枪械框架与零件，不影响近战、普通塑料或其他机器。
- A22：CNC 修正建议按 `ceil（原工作量 ×（100－修正百分比）÷100）` 计算，再按机器当前速度求晚数；不得把芯片基础工作量直接改成固定晚数。
- A23：警报同一派系多个模组仍只结算一次；不同派系目标按各自模组分别处理，等级只影响声望数值。

### 6.4 熔炉与化学设备

- A30：垃圾处理始终投入 6 垃圾，+0／+10／+12 分别产出 4／5／6 废金属。
- A31：高炉始终投入 3 材料，+0／+10／+12 产出分别为 2／3／3；只有 +12 移除纯度降低。
- A32：化学设备 +0～+9 质量为 0，+10／+11 为 10，+12 为 20；每次从当前等级重算，不累加到 30 或更高。
- A33：化学设备安装后仍遵守原版提取器拆除要求，强化不能绕过。

## 7. 售价与里程碑联动

以未强化基准价 100、无固定词条加价的专用模组为例：

| 等级 | 是否可见特殊提升 | 预期售价倍率 | 预期售价 |
| ---: | --- | ---: | ---: |
| +8 | 无 | 260% | 260 |
| +9 | 无 | 305% | 305 |
| +10 | 第一次 | 365% | 365 |
| +11 | 无，保持 +10 效果 | 440% | 440 |
| +12 | 第二次 | 560% | 560 |

断言：特殊效果不在 +11 改变，但售价仍从 365 增至 440；未解锁工艺时不能达到 +9 以上。若已解锁制造大师，+12 最终售价为 616。基础价 70 的普通模组 +10→+11 从 256 增至 308，增值 52。

## 8. UI 与只读预览

- U01：未解锁工艺且模组为 +8 时，强化按钮禁用并显示“需要王尔德：精密强化工艺”。
- U02：+9 预览显示 +10 第一次效果；+10→+11 预览明确显示“专用效果不变”。
- U03：+11 预览显示 +12 第二次效果和失败结果。
- U04：tooltip 不出现 +4、+6、+8 等旧专用效果里程碑。
- U05：芯片 tooltip 只有固定工作量；预计晚数只出现在制造预览并随性能刷新。
- U06：所有预览不扣金币、不扣材料、不掷随机数、不写标签、不推进进度。
- U07：旧存档专用模组在未购买工艺时显示 +8 上限；购买后无需重新制造即可继续强化。

## 9. 旧存档专项回归

- M01：2.1.8 旧任务缺少配方版本时按 `Legacy` 读取原工作量与进度。
- M02：旧存档的原版专用模组建立 N=0 快照，未购买工艺时最多到 +8。
- M03：异常或测试数据中的 +9 以上专用模组不被强制降级，但未解锁时不能继续强化。
- M04：禁用后恢复基础效果；重新启用且工艺已购买时按保存的 N 恢复 +10／+12 效果。
- M05：连续读档两次不重复提升产量、声望、质量或售价，不重复执行迁移。

- 工作量、上限和 19 种效果的纯规则断言全部通过。

- 所有游戏适配与 UI 用例完成实机验收。
- 至少一个 1.0、一个 2.0.x、一个 2.1.8 存档通过迁移与连续读档测试。
- 构建和官方扫描通过；但不得用构建或扫描替代上述玩法验证。
