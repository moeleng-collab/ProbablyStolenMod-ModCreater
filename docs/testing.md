# 2.x 验证计划

## 自动验证

从游戏根目录运行：

```text
python Modding/ModuleCrafter/run_tests.py
python Modding/ModuleCrafter/build.py
python Modding/ModuleCrafter/run_scan.py
```

规则测试覆盖全部 F/G 表、四档费用、成功率、失败结果、触媒、售价、学习上限／夹紧、软顶溢出和兑换，并保留一期断言。2.1.0 起覆盖强化器价值与物品 ID 映射、机器解锁条件、杰克逊概率边界、退休商人固定货量、强化器不作为制造材料，以及原版上限和负向维度预览；2.1.2 另覆盖五种结果到三个音效键的映射；2.1.8 覆盖报废模组商人货量、拾荒壳体概率边界与类型分配、改装能手 20% 边界、无特性不掷骰，以及免费报废不返触媒和免费夹保护不耗夹。三个 WAV 须核验为 44100 Hz、单声道、16 位 PCM，时长分别为 0.62、0.36、1.05 秒。扫描记录 `Refused`、`HardFlags`、`Findings`、`MethodsScanned`。

## 必做实机验收

1. 制造机不再显示强化页签，原配方、开造、取消退料、夜间完成、输出、耗电、模组舱扩建和涡轮增压器保持正常。
2. 旧版制造机强化槽分别放入模组、触媒和稳固夹后升级读档；确认物品解锁并退回商店库存，没有复制或丢失。
3. 强化器显示 3×3 铁砧外形，窗口没有电池槽、夜间进度或输出槽；材料栏只能放入一个可强化模组及允许的强化材料。
4. 把触媒、稳固夹或废金属只放在玩家／商店库存而不放进强化器，确认强化或兑换不会读取它们；放入材料栏后才可正常使用。
5. 核对当前／下一级三围、突破固有上限提示、失败结果预览；未强化旧物品打开预览后不应仅因预览就生成 B/N 标签。
6. 九种模组各从 +0 到 +12，检查三围、费用、触媒、成功／维持／掉级／报废／归零和词条；新动画能打断旧动画。
7. 钱／触媒不足时连点不重复扣费；材料栏满时兑换不扣废金属，报废优先回到原材料栏，极端空间不足时退到商店库存。
8. 带学习算法、劣化、过载、优质／劣质及各种形状的模组；存档／读档、禁用／启用后核对。
9. 背包、提示、强化面板、装机槽核对 +0、+1、+8、+9、+12 外观；动画保持 120 ms／帧，稳固夹为上排三格、下排中间一格的 T 形。
10. 制造预览与实际软顶、蒸发器合计与液体分配回归；+7→+8 至 +11→+12 面板分别显示 80%、70%、60%、55%、45%。
11. 普通 Performance 配方只放完好模组与 2 个电子元件时必须提示材料不足，换用损坏或报废壳体后才能开造；Overclock 等进阶配方仍能使用指定完好模组。
12. 杰克逊在未拥有／已拥有强化器时分别按 70%／15% 掷骰，退休商人每次提供 1 台；核对材料商人、退休商人材料货表、赃物标记和废料场单次附加触媒。
13. 2.1.3 动画／拖动专项：确认成功与各类失败动画完整播放；+12 双帧持续播放时在背包、商店和强化器材料栏之间反复拖动模组，跨越多次闪烁与结果动画结束点，确认拖拽图标始终跟随鼠标、原位置不出现双重叠层、拖动不中断且动画不冻结；新建及旧存档强化器均与制造机一样占完整 3×3 九格。
14. 2.1.2 杰克逊专项：已解锁机器后多次刷新杰克逊，核对普通／进阶芯片、触媒、回流券各 50%，稳固夹、回流核心各 20%；第 20 天不出进阶芯片和回流核心，神经芯片仍不进入杰克逊，单次中签各上架 1 个。
15. 2.1.2 音效专项：成功时只播放打铁声；维持、掉级和稳固夹归零时只播放普通失败声；+11→+12 无稳固夹失败时只播放破碎声。核对音量、延迟、连续强化时的重叠情况，并确认资源缺失或播放异常不影响扣费与结果应用。
16. 2.1.7 电流转化器专项：制造机待机、取消、完成及输出占用暂停时睡觉，服务费用均不包含制造机耗电；正常开工和跨夜制造仍按模组调整后的耗电结算。核对旧存档读档、无足够电力时不能开工，以及原版其他机器费用不变。
17. 2.1.8 来源与特性专项：退休商人核对损坏、报废模组各固定 1 个及各自 50% 追加；多次拾荒核对独立 20% 壳体掉落、两种类型和原触媒来源。无「改装能手」时强化消耗不变；拥有时分别验证免费成功、普通失败、稳固夹归零与无夹报废，确认免费时不扣金币／触媒／稳固夹，免费报废不返触媒，非免费结果仍按原规则消耗和返还；金币或触媒不足时仍不能开始强化。

以上实机项在执行并记录前均保持“待验证”，不得以自动测试替代。
