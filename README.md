# 模组制造机

Probably Stolen 正式版 0.46D 的独立玩法模组：用配方芯片和材料制造、强化模组，并围绕专精、专用效果和王尔德人脉形成经营路线。

当前版本为 **3.0.1**。清单 ID 为 `module_crafter`，Steam Workshop ID 为 `3840773884`。本项目不合并进 Next Opening: Suppliers & Odin，也不复用其工坊项目。

## 3.0 当前实现

- 新增「模组制造商」专精：开局制造机与性能芯片，拾荒 +2，制造／强化成功率 +10 个百分点。
- 19 种专用模组及主题／通用双配方，新增可堆叠通用制造组件；全部 28 种模组均可制造和强化。
- 芯片使用固定工作量，机器性能只影响动态完成晚数；专用模组未解锁「精密强化工艺」前封顶 +8，解锁后开放至 +12。
- 专用效果仅在 +10、+12 提升，售价按 V0 以新曲线最高 560% 重算，制造大师额外增加 10%。
- 新增合法／违禁芯片货源、王尔德五项升级及旧存档迁移。原始旧存档与 1.0～2.1.8 存档无需重开，但不追溯专精奖励。
- 规则测试、编译和官方扫描已完成；实机 UI、原生机器效果、存档迁移和禁用恢复仍待验收。3.0 尚未上传 Workshop。

## 2.1 已实现

- 新增独立机器「模组强化器」（`module_crafter_enhancer`），使用 48×48 铁砧贴图。原制造机不再显示强化页签，保留原制造、耗电、模组舱、输出和夜间流程。
- 强化器使用一个共享材料栏，同时容纳被强化模组、触媒、稳固夹和兑换用废金属；只允许放入一个可强化模组。所有强化与兑换材料只从该栏读取，不再读取玩家全局库存。
- 强化仍在白天即时结算，不占夜间、不耗电，也没有电池槽、夜间进度或输出槽。面板显示当前／下一级三围、是否突破原版固有上限及失败结果预览。
- 模组强化器价值 400。杰克逊在已解锁机器时按未拥有 70%／已拥有 15% 上架；退休商人每次货表固定提供 1 台。
- 2.1.2 起，杰克逊的普通／进阶制造芯片、强化触媒、回流券均为 50%，回流核心和稳固夹均为 20%；保留原有机器及第 21 天解锁条件，神经芯片不加入杰克逊。
- 读取旧存档时，旧制造机强化槽内的物品会解锁并退回商店库存，避免升级丢失。
- 九种完好通用模组支持 +0 至 +12；包含分档费用、成功率、触媒消耗、维持、掉级、报废及稳固夹归零。保留 2.0.6 已确认数值：+7→+8 至 +11→+12 的成功率为 80%、70%、60%、55%、45%。
- 可堆叠强化触媒与 T 形稳固夹保持不变；每 3 个废金属可兑换 1 个触媒，兑换前检查触媒空间，空间不足不扣废金属。
- 三围按 B/N 重算，兼容学习算法、劣化、特殊词条、形状和售价；保留等级角标、120 ms 结果动画、+12 双帧、中英文文本，以及制造软顶和蒸发器联动。
- 2.1.4 起只刷新强化叠加层和原生动画，不再调用会重置拖拽图标位置的布局刷新，并保留原位／拖拽图标的显示状态。保留原创打铁成功声、低沉钝金属普通失败声，以及重击后金属碎裂的 +11→+12 无稳固夹报废声。
- 2.1.5 修复卖家触媒和稳固夹并入玩家堆叠后无法购买、离开不清理的问题；可堆叠物品必须同时满足 ID 和所有权一致。
- 2.1.6 修复制造机自身目标判定递归导致的移动制造机及芯片／材料操作崩溃；制造、强化和商店规则不变。
- 2.1.7 修复待机制造机仍结算电流转化器费用的问题；只有进行中且未被输出占用暂停的制造任务计费，开工供电检查和夜间实际扣电仍按模组调整后的工作耗电执行。
- 2.1.8 退休商人每次固定出售损坏、报废模组各 1 个，并各有 50% 概率追加 1 个；拾荒新增独立 20% 概率获得 1 个损坏或报废模组，两者各半。拥有「改装能手」时，每次强化有 20% 概率不消耗金币、触媒和稳固夹；仍须满足正常费用与材料条件，免费报废不返还触媒。
- F9 调试台仍只在 0.x 开发版启用，2.1.8 正式版不注册。

## 1.0 已实现

- 模组制造机窗口：芯片槽、材料仓、输出槽、夜间进度、取消退料。
- 普通、进阶、神经配方芯片；材料数量固定，溢出电子元件不加成功率。2.0.6 起普通基础配方只接受损坏或报废壳体与 2 个电子元件，不再以完好模组替代壳体，也没有完好壳体加成；进阶配方明确要求的完好模组仍照常使用。
- 制造成功后，适用种类会随机原版模组形状；并再对 9 种原版特殊属性（优质、劣质、接收器、顶部挂载、侧面挂载、过载、劣化、学习算法、负反馈）各自独立掷 10%。官方最多两条，互斥规则与原版一致。
- 杰克逊博士存货：制造机、模组芯片、回流券和回流核心。来访与夜间商店独立掷骰。玩家尚未拥有这台制造机、且本次上架了制造机时，同一批存货至少再出一张普通芯片。
- 回流券在点击「开造」时立即消耗，取消不退回；回流核心永久不消耗。两者同时在材料栏时优先使用核心，不扣券。失败且有回流时退回配方材料。
- 拥有制造机后，每周一次退休模组商人，带专属立绘；第 21 天起神经芯片和回流核心有怜悯递增。
- 夜间正常完成后，第二天早报会提示取走产出；机器提示和预览在输出槽有物品时也会提醒。
- 中文和英文文本。F9 调试台仅在 0.x 开发版启用，1.0.x 正式版不会注册这些按钮。

## 开发者模式

- 默认 `build.py` 为正式发布构建：不编译调试面板、不复制 `debug.on`，也不声明 `files` 权限。
- 仅执行 `python Modding/ModuleCrafter/build.py --dev` 时定义 `MC_DEBUG`，启用 F9 的 `MC`／`MC3` 命令，并为开发清单追加 `files` 权限。
- 切回默认构建会自动删除安装目录中的 `debug.on`，调试入口和 `files` 权限同时消失。使用方式与推荐验收流程见 `docs/debugging.md`，请只在测试存档中使用。

## 构建

在游戏根目录执行：

```
python Modding/ModuleCrafter/run_tests.py
python Modding/ModuleCrafter/build.py
python Modding/ModuleCrafter/run_scan.py
```

构建会安装到 `Mods/ModuleCrafter/`。首次使用需在游戏内启用并按提示重启。不要把游戏程序集、反编译代码或官方扫描工具一并发布。
