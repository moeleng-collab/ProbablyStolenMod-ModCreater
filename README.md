# 模组制造机

Probably Stolen 正式版 0.46D 的独立玩法模组：用配方芯片和原版材料，经夜间加工制造通用模组。

当前封板版本为 **1.0.0**。本项目不合并进 Next Opening: Suppliers & Odin，也不复用其工坊项目。

## 1.0 已实现

- 模组制造机窗口：芯片槽、材料仓、输出槽、夜间进度、取消退料。
- 普通、进阶、神经配方芯片；材料数量固定，溢出电子元件不加成功率。完好壳体只给普通芯片额外 +5% 成功率。
- 制造成功后，适用种类会随机原版模组形状；并再对 9 种原版特殊属性（优质、劣质、接收器、顶部挂载、侧面挂载、过载、劣化、学习算法、负反馈）各自独立掷 10%。官方最多两条，互斥规则与原版一致。
- 杰克逊博士存货：制造机、模组芯片、回流券和回流核心。来访与夜间商店独立掷骰。玩家尚未拥有这台制造机、且本次上架了制造机时，同一批存货至少再出一张普通芯片。
- 回流券在点击「开造」时立即消耗，取消不退回；回流核心永久不消耗。两者同时在材料栏时优先使用核心，不扣券。失败且有回流时退回配方材料。
- 拥有制造机后，每周一次退休模组商人，带专属立绘；第 21 天起神经芯片和回流核心有怜悯递增。
- 夜间正常完成后，第二天早报会提示取走产出；机器提示和预览在输出槽有物品时也会提醒。
- 中文和英文文本。F9 调试台仅在 0.x 开发版启用，1.0.0 正式版不会注册这些按钮。

## 构建

在游戏根目录执行：

```
python Modding/ModuleCrafter/run_tests.py
python Modding/ModuleCrafter/build.py
python Modding/ModuleCrafter/run_scan.py
```

构建会安装到 `Mods/ModuleCrafter/`。首次使用需在游戏内启用并按提示重启。不要把游戏程序集、反编译代码或官方扫描工具一并发布。
